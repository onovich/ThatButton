# 离线整套路线 · 0.8.0

## 单位与轮换

小单位为一道预先验证的题目，大单位为40关完整路线，一组为20条路线（800题）。每条路线保留12单条件、14–15 AND、7–8 OR、6含NOT；词语10关覆盖十类各一次；质合数最多3关、后期且不相邻。单题判定、语义干扰项和组合条件独立性在电脑端校验。

设备按洗牌顺序使用20套。失败重开或全部通关后进入下一套；中途退出保持原套、题号、得分、已按格子及剩余时间。整组用尽重新洗牌，并排除上一组最后一套与下一组第一套相同。轮换进度保存在state.thatbutton.rotation。随机序列为确定性PRNG，可复现；首次安装设备使用相同初始种子。

不再逐关独立抽题，也不在设备现场重排按钮。每套题和位置固定，便于按Rxx-Lxx精确复现。跨关语义节奏沿用已确认的连接词/词语/质合数路线；不同题目主观难度仍需真机试玩。

## 离线数据与运行预算

scripts/offline-generator.lua保留电脑端生成策略；scripts/generate-bank.py生成app/domain/bank.lua及artifacts/offline-routes.json。bank.lua用20条紧凑文本保存800题；运行时只解码当前题，按答案位掩码判定，不进行规则搜索或词语抽取。未增加设备文件API，也不需要联网。当前关缓存不写入存档。

完整打包入口约103KB，桌面Lua入口堆约206KB；这是模拟测量，不代替真机watchdog验证。新存档generation9，旧动态轮次会重开。

## 0.8.1 早期形状教学

审计0.8.0题库发现R01/R02/R11首次形状条件分别到12/13/13关。现每套第1、4关必为纯形状条件，离线生成与完整路线回归均添加强制检查。保持每套连接词配额，generation10使旧题板存档重开，防止旧已按格子套入新规则。

## 0.8.2 每次打开重新开局（覆盖旧续玩行为）

退出后重新打开不再恢复游戏进度，每次启动消耗下一套，从第1关、零分、完整倒计时开始。仅保留轮换顺序、组编号和已使用位置；20套组内不重复。on_load后首次on_enter不会二次换套，on_leave后同VM重进会换套；练习设置的内部切换不会换套。generation10不变，保留0.8.1轮换记录。验证800个中途重开、失败后重开、41次连续打开、20套完整通关和3组轮换通过。

## 0.8.3 顺序循环（覆盖旧洗牌与轮换历史）

仅lastRouteId用于跨局选套。新安装从1开始，每次打开、失败重新开始、通关后再来一轮均选 lastRouteId % 20 + 1，进入时立即更新，无需通关。旧rotation.lastRoute或旧run.route迁移后删除rotation，不保留组编号/顺序数组/随机种子。旧用户从上一套的下一个ID继续，而非强制从1开始。generation10不变。60次选套及41次真实生命周期重开验证顺序循环，800关流程通过。
