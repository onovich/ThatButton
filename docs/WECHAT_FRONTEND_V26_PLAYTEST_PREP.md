## 本轮修复

实测发现重开后旧分数仍短暂留在顶栏，体力也沿用上局插值。新局重置入口 `renderer.resetRoundMotion()` 现在同时清理分数、体力和进度 tween，以及旧连击退出状态。普通换关不会调用这个重置，因此保留角色连续显示。

小游戏回归检查覆盖：上一局已完成分数插值、进入结算、重开、再次绘制后显示 0 且不残留旧分数。小游戏 check、根项目 validate 与 build 已通过。

临时诊断只改生成产物，完成后已恢复并重新构建；最终 `build/game.js` 不含 `__wechatInspection`。
