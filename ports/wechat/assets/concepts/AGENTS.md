# WeChat visual concept assets

The user accepted the main character shapes in the 2026-09-29 v11 concept. Before making new mascot art, read [the character baseline](2026-09-29/CHARACTER_BASELINE.md) and view both linked PNGs at full size.

- Use the v11 three-screen image and its transparent result-screen pair as the visual source of truth. Older concept versions are exploration history.
- Preserve the current brain and glove silhouettes, facial proportions, navy outline with thin white outer edge, character relationship, and strict limb topology. The glove has two navy legs and shoes; its pointing finger is not a leg. Never add extra pink limbs to the brain.
- Make new poses as new transparent, versioned assets; inspect them at original and phone size before compositing. Keep the approved baseline files unchanged and use deterministic composition for the final board.
- Run `2026-09-29/verify-character-baseline.ps1` after work that touches these assets. A new baseline requires an explicit user decision and a new version; do not silently replace v11.
