## 采集质量问题

所有截图场景 RAF 间隔样本为 0；超过 50ms 次数为 0 不代表没有卡顿，而是缺少该指标样本。当前 game.js 只将 canvas.requestAnimationFrame 判为 RAF；缺少此 API 会走定时器，定时器间隔按设计不算 RAF。需要核查真机全局 RAF 的可用性与实际调度，不能把定时器直接改名为 RAF。

game-entry 绘制数远多于 game，需核查 renderer 的入场状态完成后是否仍残留、造成诊断场景误分类。先修采集可信度，再决定是否需要补测。此批截图仍可证明四轮报告保留和图集命中。
