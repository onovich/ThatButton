# 0.4.0 倒计时

此前不限时适配遗漏用户要求的核心机制。本版用内置image_gen补充正常/最后5秒原画，保存于design/concepts/countdown-v1-original.png；提示词为countdown.prompt.txt。原画是设计参考，实际设备以Lua绘制实时数字及时间条。

## 规则

默认采用已向用户说明的设备节奏（可按后续偏好调整）：1–5关45秒、6–15关60秒、16–40关75秒，质数/合数槽位加15秒。它不是原版18秒至9.5秒的快节奏；原版答对加时及跨关结转暂不采用。每关独立满额开始；答对不加时；归零直接挑战结束，失败原因显示时间耗尽；误按扣生命机制不变。

结算、练习设置、练习、离开应用暂停。重试本关恢复开局生命/分数并重置时间；下一关使用其完整时限。ctx.state存储remainingMs和failureReason。0.3.x进度只补本关满额时间，保留已按集合、生命、分数及题目。0.4.0进度恢复剩余时间，不计离线时间；断电保存依赖宿主，未声称立即落盘。

45–90秒是每关上限，并非预计每关耗时。此前20–30分钟是整轮首次游玩估算，实际时长受判断速度、操作方式、失败重试影响，尚需试玩。

## 接口与绘图

使用XTApp公开契约：lua-author-api.md给出on_tick(ctx,dt_ms)；runtime.md列出normal/idle目标tick策略且不保证屏幕帧率。每tick按实际dt_ms扣减，on_draw不推进时间；仅在显示秒数变化或超时时request_refresh(partial)+invalidate。不闪烁。

条件区80–250，计时区260–308，时间条318–324，按键区340–770。最后5秒数字区域黑底白字；结果页显示冻结后的剩余秒数。整体480×800纯黑白，原有标题、形状与数学条件保持。
