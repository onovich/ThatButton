# 词语关卡 · 0.7.0

词库在 assets/words/catalog.json：10类，每类16词，共160词，全部两个汉字。类别为水果、蔬菜、动物、容器、衣物、家具、文具、乐器、交通工具、身体部位。每个词含固定素材键，按类存放；规则按显式类别成员匹配，不在设备上推断语义。

争议干扰项排除：水果和蔬菜不互作负例，容器和家具不互作负例。当前不收录多义词或依赖隐含用途的答案，例如书包不作为容器题安全答案。新增词必须人工核对分类及双字长度。

词语关固定出现在11、14、17、20、23、26、28、30、34、40关，每轮十关。类别由种子与词语关序号轮换，每轮十类各作为题目类别一次，先取类再抽词。同关不重复，不混入数字。不同轮次词语会重复；当前未保存跨轮次最近用词历史。

11/14关为单类别教学，额外2秒；17关为AND；20/23/26关为OR；28/30/34/40关为AND+类别否定。双条件随机搭配形状或图形黑白。与质合数关不重叠；质合数仍保持后期低频。黑色图形白字、白色图形黑字。

题板用构造方式保证2个禁止按钮和7个安全按钮，同时保证双条件的两种单侧干扰项存在，类别不被形状或黑白替代。先按目标匹配关系取类和词，再分配属性并打乱位置。固定种子可复现。
