# 黑白规则与关卡生成 · 0.6.0

图形只有 black/white 一个真实属性，数字颜色实时取反，不保存第二个可独立修改的颜色。每盘两种图形颜色都存在；圆、方、三角、星形均支持实心黑底白字和空心白底黑字。

## 条件与难度

- 第1–5关：单一颜色条件，可说“黑色图形”“白色图形”“黑色数字”“白色数字”。仍按原盘面禁止键数量范围筛选。
- 第6关开始：颜色 **以及** 形状/数学条件。第16关开始允许颜色 **或** 形状/数学条件。
- 每3关优先尝试一次颜色题，其余关卡每次候选有25%机会尝试颜色题。最终分布受盘面可解性、难度筛选和有限重试影响，不是固定概率。
- 质数/合数仍只进入原来的后期稀有槽；不与颜色复合，以免难度陡增。
- 40关、倒计时、一次误按即失败不变；不存在生命数值。

## 两层防护

语义层每个复合规则最多包含一个颜色原子，另一个只允许独立的形状或数学原子。两条颜色规则不直接组合：

|组合|问题|生成处理|
|---|---|---|
|黑色数字 以及 黑色图形|不可能成立|排除|
|黑色数字 或 黑色图形|覆盖全部|排除|
|黑色数字 以及/或 白色图形|两个条件等价|排除重复复合|

盘面层逐键计算禁止条件。零禁止键、全部禁止、超出当前难度禁止键数量的候选全部拒绝。颜色复合还必须存在“仅颜色符合”和“仅另一条件符合”的键，避免某个条件在该盘中完全冗余。120次候选仍失败时回退为一个唯一数字目标；此时恰好1个禁止键，其余键安全。回退可放宽该难度阶段的最低禁止键数，优先保证可玩。

## 渲染与存档

实心轮廓预绘到离屏图层，屏幕每帧使用一条layer命令复用；数字用相反的0/15颜色遮罩绘制。三角形/星形不能在数字之后重绘实心填充，否则会遮住数字。

generation由3更新到4。因为同一种子对应盘面已改变，旧版未完成挑战会重置到第1关，防止旧的已按键集合套到新盘面；本版本内部正常恢复。

## 验证

`tests/colors.py` 对792种合法单元格逐一对照颜色与数学的AND/OR真值，共6336次，并检查32种双颜色复合全部拒绝、全禁/全安全/冗余候选拒绝。`tests/campaign.py` 覆盖62种种子×40关，逐盘验证双色、反色、合法规则、至少一安全一禁止、原难度范围（回退例外）、颜色难度阶段、稀有条件限制、单次误按失败，并实际走完40关输入。通过的2480盘中有89道单色条件、720道颜色AND、136道颜色OR，其余为形状/数学题。
